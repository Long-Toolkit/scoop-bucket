# scoop-bucket

Scoop bucket for the Long-Toolkit CLI.

The toolkit supports Python `3.10` only. The full workflow requires a Linux Docker environment on Windows; installing the CLI with Scoop does not provide a native Windows Python backend. See the [installation guide](https://long-toolkit.readthedocs.io/en/latest/getting-started/#installation).

```powershell
scoop bucket add long-toolkit https://github.com/Long-Toolkit/scoop-bucket
scoop install long-toolkit
```
